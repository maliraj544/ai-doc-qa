# AI-Powered Document & Multimedia Q&A Web App

## 🚀 Features
- Upload PDF documents
- Upload audio files
- Extract text from PDFs
- Chat-based Q&A
- Summary generation
- Audio timestamp navigation
- MongoDB Atlas integration
- Fully deployed frontend and backend

## 🛠 Tech Stack

### Frontend
- React
- Axios
- Vercel

### Backend
- Node.js
- Express.js
- Multer
- pdf-parse
- MongoDB Atlas
- Render
